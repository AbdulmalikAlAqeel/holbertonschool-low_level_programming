C - Hash Tables
Description
This project covers the implementation of a Hash Table data structure in C. It focuses on the use of hash functions (specifically the djb2 algorithm), handling collisions using the Chaining method (linked lists), and understanding the trade-offs between speed and memory.


0-hash_table_create.c : Function that creates a hash table.

1-djb2.c : Implementation of the djb2 hash algorithm.
