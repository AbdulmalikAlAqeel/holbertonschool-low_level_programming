Task0 : A function that prints a name using a function pointer.
Task1 : A function that executes a function (passed as a parameter) on each element of an array.
Task2 : Searches for an integer in an array using a comparison function.
Task3 : This project is a simple command-line calculator that performs basic arithmetic operations: addition, subtraction, multiplication, division, and modulo. It uses function pointers to select the appropriate operation based on user input.

3-calc.h: Header file containing structures and function prototypes.

3-op_functions.c: Contains the logic for the operations (add, sub, mul, div, mod).

3-get_op_func.c: Contains the function that selects the correct operation function.

3-main.c: The entry point of the program.
